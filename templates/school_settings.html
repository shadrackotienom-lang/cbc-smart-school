📖 How To Use This Page — Read First

1. School Info: Name & Code appear on every report. Use official KNEC / NEMIS name & code.
2. Location: Helps parents find you & helps County reports.
3. Leadership: Principal / Deputy / Bursar names appear on report cards & receipts.
4. Contacts: Phone / Email / WhatsApp are used to contact parents & for SMS.
5. Money: M-Pesa Till / Paybill + Bank details appear on Fee Receipts so parents know where to pay. If you don't have Paybill, leave blank.
6. Term: Set Current Term & Year — Dashboard, Fees & Results use this.
7. Save: Click 💾 Save Settings at bottom. If page is empty, it means no school was created yet — go to Schools → Add School first, then come back here.
