✅ How to Backup (Manual)

1. Stop server (Ctrl + C)
2. Copy db.sqlite3 file
3. Paste to Desktop / Google Drive / USB
4. Start server again

🔄 How to Restore

1. Stop server
2. Replace db.sqlite3 with your backup copy
3. Run py manage.py runserver
4. All data comes back
